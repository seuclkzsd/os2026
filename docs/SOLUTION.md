# hsolve 方案说明文档

> 面向电磁谐振与微波器件仿真的大规模非正定厄密稀疏矩阵特征值求解方案
> （交付物 a；版本：P2 完成 + P3 进行中，评测数据随实验更新。实现细节契约见 `docs/DESIGN.md`）

---

## 1. 问题、目标与求解边界

### 1.1 问题类型

| 类型 | 形式 | 电磁背景 |
|---|---|---|
| HEP | A x = λ x，A 厄密不定 | 已做质量矩阵变换的本征问题；光子晶体 Bloch 问题（复厄密） |
| GHEP | A x = λ B x，B 厄密正定 | 谐振腔（curl-curl 刚度 / 质量），Yee 网格 |
| GHIEP | A x = λ B x，B 厄密**不定** | **波导模式分析**（Lee–Sun–Cendes 棱元-节点元混合公式，λ = −β²）——宣讲真实算例即此类 |

宣讲真实算例（293 阶）的谱结构我们完整复现：A 惯性 149/66/78、B 惯性 227/0/66、广义谱 18 负 / 66 零 / 209 正，
其中 18 个负特征值正是 10 mm 方波导在 50 GHz 下的 18 个传播模（TE 12 个 + TM 6 个），66 个零特征值是
节点自由度对应的非物理零空间。

求解目标：σ 附近最近的 k 个（默认）、区间 [a, b] 内全部、代数最小 / 最大的 k 个。

### 1.2 求解边界（能处理 / 不能处理）

| 能处理 | 说明 |
|---|---|
| 实对称、复厄密（A、B 任一为复数） | 复厄密经实对称嵌入统一走 LDLᵀ |
| A 不定；B 正定或不定 | B 正定性自动判定（Sylvester 惯性，或对角 B 的符号） |
| σ 位于谱内部、贴近特征值、精确落在特征值上、落在稠密簇内 | 见 §2.5 |
| 精确重特征值、零附近密集谱 | 惯性证书 + 收缩重跑（B 正定时可证明完备） |
| 分解内存超预算 | 预估后自动转 out-of-core；仍超则拒绝并报告估计值，绝不盲目分解 |

| 不能处理 / 有条件 | 处理方式 |
|---|---|
| 非厄密矩阵（如复对称 PML） | 输入检查直接拒绝（`NotHermitian`），不给错误答案 |
| GHIEP 的完备性证明 | Sylvester 惯性对不定 B 不计数，报告中明确注明「证书不可用」 |
| GHIEP 中把精确多重的零簇本身作为目标 | 单向量 Krylov 无法保证取全副本；采用移位放置使零簇不被需要（P3） |
| 区间内特征值极多（> max(2000, n/2)） | 谱切片（P3） |

## 2. 算法原理

### 2.1 位移反演 + Krylov-Schur（主路径）
K(σ) = A − σB，Op = K⁻¹B，A x = λBx ⇔ Op x = θx，θ = 1/(λ−σ)：离 σ 最近的特征值变为模最大，
Krylov 方法对模最大部分收敛最快。B 正定时 Op 在 B 内积下自伴，用**厚重启 Lanczos（厄密 Krylov-Schur）**，
全 CGS2 重正交化（B 内积，按需重算 B·w，不存 B·V 以省内存），已收敛对在耦合降到工作精度时锁定。
B 不定时用**一般 Krylov-Schur**（实 Schur 形 + dtrsen 重排，共轭对永不拆开）。

### 2.2 对称不定分解与复厄密实嵌入
现有工具卡在「只能处理正定矩阵」——本质是用了 Cholesky。K(σ) 在谱内部必然不定，我们用 MUMPS 的对称不定
LDLᵀ（Bunch–Kaufman 型 2×2 主元）。MUMPS 的复数 SYM=2 是复对称而非厄密，因此复厄密 K 改为分解其实对称嵌入
E = [[Re K, −Im K],[Im K, Re K]]（2n 阶）：求解 E[Re x; Im x] = [Re b; Im b]，且 inertia(K) = inertia(E)/2；
浮点运算量与内存与复数 LU 相当，同时得到惯性。

一个分析服务所有分解：`ShiftedPencil` 只存 A ∪ B 的上三角并模式索引，αA+βB 的值直接写入 MUMPS 数组，
任意位移 K(σ)、B 本身、证书端点都复用同一次符号分析，完整 K 从不物化。

### 2.3 完备性证书（「不漏根」）
B 正定时，Sylvester 惯性定理给出 ν₋(A − sB) = 小于 s 的特征值个数（LDLᵀ 负主元数）。对目标窗口 [a, b]
（Nearest：a ≤ σ−r、b ≥ σ+r，r 为找到的 k 个中最远距离，端点推到谱隙中点；Smallest/Largest 单侧；
Interval 为用户区间）：

  count_inertia = ν₋(A − bB) − ν₋(A − aB)，与找到的互相 B 正交的特征向量数比较。

不等则以已收敛向量为收缩块重跑，直到相等——**结果是可证明完整的**。实测（§9）对照组 SLEPc 在 3/15 个测例上
漏掉重特征值副本而无任何告警，hsolve 全部正确。

### 2.4 不定 B（GHIEP）
一般 Krylov-Schur 得到 Op 的 Schur 基；取各 Ritz 向量的实部与虚部张成实子空间（近实的共轭对——如零簇的
±1e-16i 噪声对——由此还原成实向量），在该子空间上解投影后的小型不定铅笔（LU + Schur），得到精修特征对。
实/复分类按问题尺度与残差双重判据：|Im λ| > complex_tol·max(|λ|, scale) **且** 实投影对的后向误差不达标而
复对达标，才判为真复特征值，单独输出（不影响实特征对的格式）。

### 2.5 近奇异与稠密簇位移
- σ 精确落在特征值上：MUMPS 零主元检测（ICNTL(24)=1 且 CNTL(3)>0——实测 CNTL(3)=0 时 3600 阶精确奇异矩阵
  也会「成功」分解）判定奇异 → σ 微扰 1e-8·scale，最多两次。
- σ 落在比检测阈值更密的簇内（任何附近位移都被判奇异）：移开 σ 会改变「最近」的集合，因此**在 σ 处关闭零主元
  检测直接分解**——保留的极小主元恰好放大所需的近零空间方向（等价逆迭代）。证书端点在同一谱隙中点先做
  有检测的计数，失败再做无检测计数（向后稳定的 LDLᵀ 对距端点 ≫ eps·‖K‖ 的特征值计数精确）。
- 实测：σ=0 落在 1000 个间距 1e-9 的零簇中心，取最近 20 个，绝对误差 ~1e-17，证书通过（§9）。

### 2.6 精修、验证与补救
HEP/GHEP 在原问题上做 Rayleigh–Ritz（hegv），GHIEP 用 §2.4 的投影铅笔。每个特征对计算真实残差
‖Ax − λBx‖₂、相对残差与后向误差 η（§5.2）。不达标者做残差修正迭代 x ← x − K̃⁻¹(A − ρB)x（ρ 为 Rayleigh 商；
对任意近似分解 K̃ 其不动点都是精确特征对）。

## 3. 复杂度分析

设 n 为阶数，Z = nnz(K)，L 为因子条目数，k 为目标个数，m（ncv）≈ 2k+1 为子空间维数。

| 阶段 | 时间 | 内存 |
|---|---|---|
| 排序 + 符号分析 | AMD ≈ O(Z)，嵌套剖分 ≈ O(Z log n) | O(Z) |
| 数值分解 | 二维 O(n^{1.5})，三维 O(n²)（嵌套剖分） | L：二维 O(n log n)，三维 O(n^{4/3}) |
| 每次 Op 作用（回代） | O(L)，访存受限 | — |
| 每步正交化（CGS2） | O(n·m)，访存受限 | 基 n·m |
| 每次重启 | O(n·m·k) BLAS3 | — |
| 证书 | 2 次数值分解（复用分析） | 同一分解对象，无额外常驻内存 |

总时间 T ≈ T_analysis + (1 + 2[证书] + 1[非对角 B 的正定性检测])·T_factor + N_solve·T_solve + O(n m² · 重启数)，
实测 N_solve ≈ 3k。k 增大时 T_solve 部分线性增长，T_factor 与 k 无关。

## 4. 预处理策略

1. **输入归一**：npz/npy/mtx 读入后合并重复项、恢复三角存储、厄密性检查；缺陷在容差内则替换为 (A+Aᴴ)/2，
   保证分解（只读一个三角）、算子与残差看到同一矩阵。
2. **铅笔并模式**：一次计算 A ∪ B 上三角并模式与散射映射，所有位移共用（§2.2）。
3. **自适应排序**（`ordering=-1`）：先做极快的 AMD 分析探测，按代价模型预估嵌套剖分（SCOTCH）能省的分解与
   回代时间，超过其额外分析代价才改用 SCOTCH。实测（8 线程）二维波导 1e5：1.65 → 1.20 s；二维腔：1.17 →
   0.47 s；三维问题自动选 SCOTCH（分析比 METIS 快 35–50%，总时间相当或更好）。
4. **缩放**：MUMPS ICNTL(8)=7，每次分解按当前数值重算，使同一分析适用于不同位移。
5. **谱变换**：位移反演（§2.1）；B 正定性判定（对角 B 直接看符号，免分解）。

## 5. 收敛性分析

### 5.1 收敛速度
位移反演 Krylov-Schur 对第 i 个目标的收敛因子约为 |θ_{k+1}|/|θ_i| = |λ_i − σ|/|λ_{k+1} − σ|（λ_{k+1} 为第一个
不需要的特征值）。σ 置于目标频段中心使该比值最小；k 个目标与第 k+1 个之间的谱隙越大收敛越快。

### 5.2 停止判据与后向误差
内层判据：Ritz 估计 ≤ tol_in·|θ|（tol_in = 0.1·tol）。由 (A−λB)x = −(1/θ)(A−σB)(Op x − θx) 得
‖(A−λB)x‖ ≤ ‖K‖·est/|θ|，故后向误差 η = ‖r‖/((‖A‖₂ + |λ|‖B‖₂)‖x‖) ≲ tol_in。最终以真实残差验收 η ≤ tol。
‖·‖₂ 取 30 步 Lanczos 的最大 |Ritz 值|——它是 ‖·‖₂ 的**下界**，因此计算出的 η 是真实后向误差的**上界**，
验收偏保守（1-范数是上界，会使 η 偏乐观，故不用）。

### 5.3 停滞处置
达到 max_restarts 仍未收敛的对标记为未接受；证书不通过触发收缩重跑（最多 2 轮）；残差不达标触发残差修正迭代；
所有事件写入日志与报告。

## 6. 并行方案

| 组件 | 并行方式 |
|---|---|
| MUMPS 分解 / 回代 | OpenMP + L0-OpenMP 子树并行（ICNTL(48)=1；比确定性模式回代快 1.75 倍） |
| 稠密核（正交化、Rayleigh–Ritz、重启旋转） | OpenBLAS（OpenMP 版）BLAS2/BLAS3 |
| 稀疏核（SpMV/SpMM、铅笔装配、输入转换） | OpenMP 行并行 |

线程扩展实测（syn-mem27-46，三维，n≈1e5）：

| 线程 | 总时间 | 分析（串行） | 分解（3 次） | 回代 |
|---|---|---|---|---|
| 1 | 12.38 s | 1.07 | 7.85 | 3.15 |
| 2 | 7.97 s | 1.08 | 4.62 | 2.09 |
| 4 | 5.44 s | 1.08 | 2.73 | 1.49 |
| 8 | 4.36 s | 1.08 | 1.76 | 1.42 |

分解扩展良好；回代受内存带宽限制（P3：块 Krylov 多右端项回代）；分析串行（由自适应排序缓解）。
GPU：赛题允许但非必需；当前为纯 CPU 实现，无 GPU 时即为完整功能（降级模式无需特殊处理）。

## 7. 故障场景与诊断流程

| 故障场景 | 检测 | 处置 | 验证（实测） |
|---|---|---|---|
| 零附近密集谱（低频击穿） | 零主元检测在所有附近位移触发 | σ 处无检测分解 + 谱隙中点计数 | syn-zero-cluster：绝对误差 ~1e-17，证书通过 |
| 重特征值 | 证书计数 > 找到个数 | 收缩重跑补齐副本 | Yee 谐振腔、方波导简并模全部取全（SLEPc 漏根） |
| 近奇异位移（σ 贴近谐振点） | 零主元（INFOG(28)）或 INFO=−10 | 微扰 σ / 簇内无检测分解 | syn-near-singular（σ = λ(1+1e-12)）：误差 9e-16 |
| 内存受限 | MUMPS 分析阶段预估（INFOG(16/26)） | 内存外分解；超限则拒绝并报告 | PARSEC 10 万阶（因子预估 7–9 GB > 7 GB 预算）：自动 OOC，结果正确 |

诊断流程：每次运行输出 `report.json`（残差三件套、证书、分解统计、计时、峰值内存、告警）与 JSON-lines 事件日志
（分析、排序决策、分解、Krylov 每次重启、证书各轮、补救），可据此定位：精度问题看 pairs/rescue，漏根看
certificate，性能看 factor_stats 与各阶段计时。

## 8. 安全设计

- **禁止硬编码**：所有参数由矩阵性质与配置按文档化规则推导（排序代价模型、位移扰动、证书端点等）；
  公开测例的特定数值从不出现在代码中。
- **参考解物理隔离**：测例输入在 `data/cases/`，参考解在 `data/refs/`；求解器 CLI 只接收 `--A --B --config --out`，
  从不获得参考解路径；测例元数据中禁止携带参考值（`tools/case.py` 强制检查）。
- **数据保护**：日志与报告只含规模、范数估计、计时与统计，不含矩阵元素；特征向量只写入用户指定目录。
- **资源安全**：内存预算先于分解检查，并作为 MUMPS 工作内存上限（ICNTL(23)）传入，超限变成可处理的错误
  而不是被系统杀掉；开发期所有运行经资源看门狗（绑核、进程树 RSS 上限、高水位峰值统计）。
- **开源依赖**：全部依赖开源（`docs/DEPENDENCIES.md`），无闭源服务。

## 9. 评测结果（持续更新）

对照组：SLEPc 3.26（Krylov-Schur + 位移反演 + **同版本 MUMPS 5.8.2**，给予最有利配置：问题类型由元数据告知、
B 正定用 Cholesky、收敛判据与 hsolve 同为后向误差）。4 核、tol = 1e-10、15 个测例（`results/cmp4b.md`）：

| 指标 | hsolve | SLEPc |
|---|---|---|
| 结果正确 | **15/15**（精确参考误差 1e-16 ~ 1e-18） | 3 个错误集合（漏重根，误差 5e-4 ~ 2e-3）+ 4 个未收敛 |
| 端到端总时间 | **48.8 s** | 69.3 s |
| 纯求解时间 | 48.8 s（含完备性证书） | 31.3 s（无证书） |
| 峰值内存 | 全部 ≤ SLEPc | — |

（P3 完成后以 16 核独占重测，并补充大规模测例与故障场景验证矩阵。）

```bash
conda env create -f env/environment.yml && source env/activate.sh
tools/dev/build.sh release && tools/dev/test.sh release
./build/release/hsolve --A A.npz [--B B.npz] --config config.json --out out/
```
